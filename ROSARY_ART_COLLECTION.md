## Download Instructions

### **Recommended Approach:**
1. Visit each URL in a web browser
2. Look for the "Original file" or highest resolution version
3. Right-click and "Save Image As"
4. Name them according to the pattern: `{number}-{short-name}.jpg`
5. Convert to WebP format for better compression if desired (optional)

### **Alternative Batch Download Script:**
```bash
#!/bin/bash
cd assets/images/mysteries/

# Joyful Mysteries
wget -O joyful/1-annunciation.jpg "https://upload.wikimedia.org/wikipedia/commons/0/04/Fra_Angelico_-_Annunciation_-_San_Marco_Altarpiece.jpg"
wget -O joyful/2-visitation.jpg "https://upload.wikimedia.org/wikipedia/commons/7/7f/Visitation_Giotto_Arena_Chapel.jpg"
# ... continue for all mysteries
```
