# Apple Review — Resolution Center replies (Guideline 2.1, Information Needed)

Each app got this same bounce. Reply in each app's **Resolution Center** (App Store
Connect → My Apps → app → version page → Resolution Center → "Reply"), attach the screen
recording for that app, paste the matching block below, then click **Submit the version
for review** again on the same build (bottom of the version page).

## How to record (2 minutes per app)

1. On the iPhone: **Control Center → Screen Record** (long-press if not in the panel)
2. Record the flow listed under the app below (60–90 s is plenty) — start from launch
3. Stop the recording → it lands in Photos → AirDrop/attach it in the Resolution Center reply

---

## Per-app recording scripts

- **Bible** — launch → "Continue reading" → pick a chapter → adjust font size → search a
  word (e.g. "mercy") → open a result → Settings screen briefly (theme + translation list)
- **Examen** — launch → Today's examen → tap through 3–4 of the examination questions →
  the guided confession walkthrough for one step → the reminder/settings screen
- **Devotionals** — launch → Today screen → open Divine Mercy Novena → read Day 1 → mark
  the day complete → the commitment-tracker view
- **Calendar** — launch → today card (season + liturgical colour) → month view → tap a
  feast day → its detail page
- **Novena** — launch → novena list → open one → that day's prayers → mark the day prayed →
  the 9-day overview
- **Prayer** — launch → prayer library → open the Rosary → open another prayer (litanies) →
  favourite a prayer → adjust text size
- **Saints** — launch → list → search "Joseph" → open a profile → the prayer tab
