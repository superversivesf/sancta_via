# Rosary Assets

This directory contains rosary-specific assets.

## Contents

- Bead images for the rosary interface
- Cross/center piece images
- Audio files for guided prayers (optional)
- Animation assets for bead progression

## Naming Convention

- `bead_hail_mary.png` - Hail Mary beads
- `bead_our_father.png` - Our Father beads (larger)
- `bead_glory_be.png` - Glory Be separator beads
- `cross.png` - Rosary cross
- `center_piece.png` - Rosary center medal
