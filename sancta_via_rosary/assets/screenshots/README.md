# Screenshots

This directory is for app store screenshots.

## iOS App Store

Required sizes:
- 6.7" iPhone: 1290x2796
- 6.5" iPhone: 1284x2778
- 5.5" iPhone: 1242x2208
- iPad Pro: 2048x2732
- iPad: 2048x1536

## Google Play Store

Required:
- Phone: 1080x1920 (9:16)
- 7" tablet: 1080x1920
- 10" tablet: 1920x1080

## macOS App Store

Required:
- 1280x800
- 1440x900
- 2560x1600
- 2880x1800

## Naming Convention

- `ios_phone_01_home.png`
- `ios_phone_02_rosary.png`
- `ios_phone_03_mysteries.png`
- `android_phone_01_home.png`
- etc.
