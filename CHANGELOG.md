# Changelog

All notable changes to the bible_data package will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-07-09

### Added
- Initial release of bible_data package
- Catholic Bible texts with search and lookup capabilities
- Pure Dart implementation with no external dependencies
- Comprehensive Bible verse access and search functionality
- Support for multiple Bible translations
- High-performance text search capabilities
- Zero-overhead access to Catholic Bible data

### Features
- Complete Catholic Bible text data
- Fast verse lookup by book, chapter, and verse
- Text search across all books
- Metadata for books, chapters, and verses
- Pure Dart implementation for cross-platform compatibility
